# docs/changes-datetime-prefix

## O que mudou e por quê

Adicionado prefixo `YYMMDDHHMM` (timestamp de criação) aos arquivos em `docs/changes/`, garantindo ordenação cronológica natural pelo nome do arquivo.

Atualizado o `CLAUDE.md` para refletir a nova convenção: o nome do arquivo de change agora segue o padrão `<YYMMDDHHMM>-<branch-name>.md`.

## Impacto no front-end

Nenhum. Mudança restrita a documentação interna e convenção de workflow.
